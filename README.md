# Zodiac Sign Generator (Salesforce LWC)

A Lightning Web Component that generates a user's zodiac sign based on their Date of Birth.

## Features

- Enter Name
- Select Date of Birth
- Generate Zodiac Sign
- Shows:
  - Zodiac Emoji
  - Zodiac Element
  - Planet
  - Lucky Color
  - Lucky Number
  - Personality Traits

## Technologies

- Salesforce LWC
- JavaScript
- HTML
- CSS
